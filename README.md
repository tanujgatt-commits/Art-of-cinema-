# The Art of Cinema

A cinematic-themed multi-page website built using HTML, CSS, and JavaScript. This project explores different aspects of movies, filmmaking, and film culture through a visually engaging collection of web pages.

## Overview

"The Art of Cinema" is a passion project designed to showcase the art and craft of filmmaking. The website contains multiple pages covering a variety of movie-related topics such as:

- Difference between cinema, film, and movie
- Influential directors and their signature styles
- The language of lenses
- Great actors and actresses
- The underrated role of screenplay
- Magnum opus films
- TV shows vs movies
- Physical media vs digital media
- Favorite films

## Features

- Multi-page website structure
- Cinematic theme and custom styling
- Responsive layout
- Movie-inspired visual design
- Navigation bar for easy browsing
- Image and media-rich content
- Simple static web project setup

## Tech Stack

- HTML5
- CSS3
- JavaScript
